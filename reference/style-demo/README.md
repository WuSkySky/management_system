# 界面风格参考 Demo

此目录是**独立的、使用虚构数据的视觉示例**，不是真实生产管理系统项目，也不是已经确定的页面结构。

可参考白底、克制用色、少分割线、简短文案和响应式处理方式。颜色、字号、留白与间距也都可以根据真实需求调整。完整记录见 [前端风格文档](../../docs/ui-style.md)。

品牌名、侧边栏、底部导航、指标、生产单、进度、日期和交互均为占位内容。开发真实系统时，应根据后续需求决定页面排版、数据和功能，不要直接沿用。

本地运行：

```bash
npm install
npm run dev
```

此 Demo 没有登录、Worker 或数据库，也未部署到 Cloudflare。
